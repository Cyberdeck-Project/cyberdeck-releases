# Cyberdeck Releases repository file guide

This public repository is the anonymous update feed used by installed Cyberdeck clients. Its file inventory was read from `main` on 2026-11-19 and updated to include the repository-local `AGENTS.md` pointer and this repository's `README.md`. The files are deliberately encrypted update packages with detached signatures; the repository does not contain the installer, source code, diagnostic reports, or signing private key.

## How to read the filenames

Each version is published as a matched pair:

- `Cyberdeck-Application-Update-<version>.cybenc` is the encrypted Windows update package downloaded by Cyberdeck.
- `Cyberdeck-Application-Update-<version>.cybenc.sig` is the detached Ed25519 signature that authenticates that exact package before the client decrypts or installs it.

The version is part of both filenames. Do not mix a package with another version's signature, manually replace files, or add installers, source archives, private keys, diagnostic data, or plaintext update packages. GitHub Actions in the private application source repository owns publishing.
